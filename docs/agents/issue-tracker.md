# Issue Tracker: GitHub

This repo uses **GitHub Issues** on `Sarveshero3/corrobor8` as its issue tracker.

## CLI

Use the `gh` CLI for all issue interactions:

```bash
gh issue list
gh issue create --title "<title>" --body "<body>" --label "<label>"
gh issue view <number>
```

## Pull Requests as a Triage Surface

- **External PRs as triage surface**: No. In-flight PRs and standard collaborator development are handled via standard Git branch workflows.
