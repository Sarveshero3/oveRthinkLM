# Triage Label Vocabulary

This repo maps the five canonical triage roles to the following label strings:

- `needs-triage` — maintainer needs to evaluate
- `needs-info` — waiting on reporter / user clarification
- `ready-for-agent` — fully specified, AFK-ready for autonomous execution
- `ready-for-human` — needs human decision or implementation
- `wontfix` — will not be actioned
